# Bramblekin

An online creature-collecting adventure in a **shared world**. Pick one of three companions, explore **ten towns** linked by
nine routes, meet wild creatures in the tall grass, weaken them and throw an orb to catch them: **150 original creatures** to
discover, most of which evolve. Beat the leader of each of the **eight arenas** to earn their badge, then challenge the League at
Bramble Peak. Every player walks on the same maps: you see the others move, react with emotes, **challenge them to a duel**
(level 50 for everyone, Elo ranking) or **trade** creatures with them. French and English, keyboard, mouse and touch.

The adventure starts like a real one: Professor Hawthorn introduces the world, you wake up in your room, your mother sends
you to the lab, the professor stops you if you try to leave the village alone, and you pick your companion from one of three
orbs on his table. Every building can be entered: healing centres (nurse behind the counter, storage box), shops, houses,
arenas and the League.

Each new player wakes up in a private room (the rest of the world is shared) with a world map in their bag. Villagers give
key items (a bicycle that doubles your speed outdoors, a Cut capsule to trim the bushes hiding rare items, a Surf capsule to
cross ponds, a golden charm for bigger rewards), and houses, bushes and ponds hide technical capsules (each teaches a move),
rare candies and awakening stones.

All creatures, names, maps and graphics are original and generated by code (no image files except the app icon): smooth HD
scenery with shadows, animated grass and water, creatures shaded like little toys, and a clean, modern interface.

## Features

- **150 creatures** in 10 types (Normal, Flame, Water, Leaf, Volt, Rock, Wind, Frost, Venom, Spirit) with a type chart,
  derived base stats, level-based learnsets (moves wait for your choice when four are already known) and evolutions.
  Each creature is drawn pixel by pixel from its lineage, stage and types.
- **The world**: 10 towns (healing centre, storage box, shop, signs and villagers), 9 winding routes with tall grass, ponds,
  trainers and items, 8 arenas and the League. Maps are generated deterministically from their name; tests check that every
  route can be crossed, every character reached, every warp leads somewhere, and every creature can be obtained.
- **Battles** decided by the server: damage formula, same-type bonus, critical hits, accuracy, priority, speed order, stat
  stages, poison / burn / sleep / paralysis, catching with three kinds of orbs, running away, experience shared with the bench,
  money and badges, and a black-out that sends you back to the last healing centre.
- **Shared world**: the PHP server validates every step (walls, speed), broadcasts positions to players on the same map,
  handles invitations, **duels** (45-second turns, automatic action when a player lingers, forfeit on disconnect, ranked
  with anti-collusion by IP from `openprunus/arcade-core`) and **trades** (both offer, both confirm).
- **No account**: each browser has a secret token (only its SHA-256 hash is stored). The save lives on the server; the
  "Code" menu shows the token so the game can be resumed on another device.
- **Phone friendly**: tap a tile to walk there (path finding), tap a player to challenge them, on-screen pad with A/B buttons,
  portrait and landscape layouts, installable as a PWA.

## Quick start

```bash
docker compose up --build        # site on http://localhost:8094, game server on ws://localhost:8095
```

Or without Docker (PHP 8.5 with mbstring):

```bash
composer install
php server/server.php            # game server on :8081 (saves in web/data/players/)
php -S 0.0.0.0:8080 -t web       # website
```

## Configuration

| Variable | Default | Meaning |
| --- | --- | --- |
| `BRAMBLE_WS` | *(same host)* | WebSocket URL seen by the browser (`wss://host/ws` behind HTTPS) |
| `BRAMBLE_DATA_DIR` | `web/data` | Player saves (`players/`) and duel ranking (`ratings.json`) |
| `WS_PORT` | `8081` | Game server port |
| `WS_ALLOWED_ORIGINS` | *(all)* | Comma-separated list of allowed origins |
| `TRUSTED_PROXIES` | *(private networks)* | Reverse proxies whose `X-Real-IP` is trusted |
| `BRAMBLE_MAX_CONN_PER_IP` | `10` | Simultaneous connections per address |
| `BRAMBLE_MAX_ACCOUNTS_PER_IP` / `BRAMBLE_MAX_PAIR_MATCHES` / `BRAMBLE_ALLOW_SAME_IP` | `3` / `4` / `0` | Ranked duel guards |
| `BRAMBLE_ENCOUNTER_RATE` | `0.12` | Chance of a wild encounter per step in tall grass |
| `BRAMBLE_TURN_SECONDS` | `45` | Duel turn timer |
| `BRAMBLE_INVITE_TTL` | `30` | Lifetime of a duel or trade invitation |

## Code

- `src/Content` — types, moves, the 150 species (`Lines.php` is the lineage table), items.
- `src/Creature/Kin.php` — an owned creature: stats, experience, learning, evolution, serialization.
- `src/Battle` — the battle engine (wild, trainer, duel) producing an event log the browser replays.
- `src/World` — deterministic world generator (towns, routes, arenas, League, encounter tables, trainers).
- `src/Player` — saves (one JSON file per player), `src/Ranking` — Elo, `src/Game` — the WebSocket hub.
- `web/js` — client: `world.js` (map, movement prediction, other players), `battle.js`, `ui.js`, `sprites.js`, `tiles.js`.

## Tests

```bash
composer check                   # PSR-12, PHPStan level 8, PHPUnit
npm run test:unit                # sprites, translations, PWA
npm run test:integration         # real PHP server + WebSocket bots (walking, duel, trade, wild battle, saves)
npm run test:browser             # headless Chrome: desktop, phone portrait and landscape, duel against a bot
```

`PHP_BIN` and `CHROME_BIN` select the binaries; `SHOTS=/dir` saves screenshots during the browser tests.
